# AQABSI V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]` / `- [x]`) syntax for tracking.

**Goal:** Build a safe, self-contained, cross-platform AQABSI skill that produces professional PRDs and deterministic evidence-backed QA artifacts across relevant testing layers.

**Architecture:** A root skill routes progressively to shared references and legacy plugin entrypoints. Standard-library Python helpers validate package links/schemas and transform a JSON test-run manifest into sanitized Markdown, CSV, XLSX, Confluence draft, and deduplicated ClickUp drafts.

**Tech Stack:** Markdown, JSON Schema 2020-12, Python 3 standard library, `unittest`, GitLab CI YAML examples.

**Spec:** `docs/superpowers/specs/2026-11-12-aqabsi-v1-design.md`

## Global Constraints

- Preserve Claude plugin compatibility and the existing 96 knowledge modules.
- Keep external mutations dry-run by default and require exact authorization before publication.
- Do not add runtime dependencies.
- Do not commit or push without a separate user request.
- Never expose credentials, tokens, cookies, or unnecessary personal data in generated artifacts.

## Review Focus

- Missing or malformed run fields must fail safely without partial artifacts.
- Secret-like keys and bearer tokens must be redacted in every output format.
- Repeated failures must produce a stable fingerprint for deduplication.
- Spreadsheet output must be a valid XLSX archive with readable test rows.
- Broken local references must fail package validation.
