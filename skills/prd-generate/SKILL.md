# Generate PRD

## Overview
Bikin PRD saja dari analisa kode.

## When to Use
- Butuh PRD.
- Tidak butuh test case / testing.

## Core Pattern
1. Clone repo (URL dari ticket).
2. Analisa code → alur, logika, aturan, cara kerja.
3. Tulis PRD dari hasil analisa.

Detail: `../../references/flow.md`.
